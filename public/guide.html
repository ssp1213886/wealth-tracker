投资策略

本工具围绕「永久核心仓 + Covered Call 增强」策略设计，仅卖出 CALL、不卖正股（不做空、不卖标的）：

  • 核心仓永不动：VGT / SMH / BTC ETF（美股代码 BTC，非现货 BTC）按月定投，侧边栏可调节分配比例
  • Covered Call 收租：仅针对 VGT / SMH，持有正股卖出虚值 CALL，收获权利金
  • 被动行权 T+1 买回：若 CALL 被行权（股价涨超行权价），T+1 手动买回正股，保持仓位不变
  • 权利金复投：权利金收入按核心仓比例继续买入标的
  • 回撤应对：回撤时通过定投加仓降低成本，不增额外风险
核心铁律：
① 不卖标的 — 只卖 CALL、不卖正股，永不做空
② 被动行权 — 被行权后 T+1 买回，不提前平仓
③ 权利金复投 — 权利金按比例持续买入标的

1. 页面结构

本网站由 4 个页面组成，桌面端用顶部 Tab、移动端用底部导航切换，切换时提供轻微触觉反馈。其中「记录」页内部再分为 明细 与 日志 两个分段，顶部还有一个跨分段生效的搜索框。

📊 仪表盘

  • 总资产指标：账户现金、持仓市值、浮动盈亏、总盈亏
  • 📋 本月定投目标：VGT/SMH/BTC 动态金额 + 完成/待执行状态
  • 🗺 20年旅程：时间进度条（可配置起始日期和年龄）
  • 💎 目标进度：可配置财务目标进度条（带 shimmer 动画）
  • 📉 高点回撤：各标的数据历史交易峰值跌幅 + 回撤进度条
  • 📈 仓位盈亏：按标的汇总盈亏
  • 🍩 持仓分布：环形图 + 现金池标注
  • 💎 Covered Call：本月 CC 收入卡片
  • 期权持仓：活跃期权合约摘要（标的/类型/行权价/张数/到期日）

🕹️ 操作台

  • 买卖录入：手动录入交易（日期、标的、数量、价格），支持 VGT/SMH/BTC
  • ⚖️ 年度再平衡：仅 12月31日解锁执行，其他日期可预览计算结果（换仓/注资两种模式）

期权

  • 持仓指标：VGT/SMH 持仓市值、成本、可卖张数 + 可复投金额
  • 🎯 OTM 行权价参考：VGT/SMH 按百分比自动计算 CALL 行权价，可手动调节后 localStorage 记忆
  • 📝 记录期权：录入 CALL/PUT 合约（标的、类型、行权价、权利金、到期日、张数）
  • 期权状态：当前活跃期权的盈亏状态 — 实值（ITM）CALL 显示蓝色「临近行权」标签（显示剩余天数），附带铁律提示文字
  • CC 收入：本月 + 累计权利金汇总 + 可复投金额
  • 持仓清单：当前持有合约（含张数、到期状态、实值/虚值标记），每行右侧显示「距现价 ±x%」（正数=仍虚值，负数=已进入实值），行权 / 结算 / 删除按钮在右下角
  • 持仓不足只软提醒：卖出 CALL 的股数不够时只弹提示并说明「仍会记录」，不硬拦；可卖张数在期权页顶部实时更新

📁 记录 · 明细

  • 🔍 搜索：输入标的 / 日期 / 金额即可筛选，命中的卡片会自动展开，右上角显示命中条数，点 × 清除
  • 💰 现金管理：入金/出金/修正/股息 + 余额
  • 📊 持仓明细：标的/持仓/均价/市值/盈亏/收益率，支持列排序（不显示现价，避免与行情卡片重复）
  • 📋 交易历史：方向标签直接写明「买入/卖出多少股」，带标的筛选、列排序，删除按钮在右侧
  • 💵 资金流水：出入金记录 + 修正记录 + 权利金蓝色独立显示 + 股息橙色独立显示
  • 📈 年度归因：选择年份查看当年总收益拆解（各标的增值 + CC 权利金 + 股息 + 其他）

📜 记录 · 日志

  • 📋 操作日志：所有录入 / 删除 / 同步动作的流水，可清空
  • 📊 年度复盘矩阵：4行×5列热力方格，年度权利金贡献率（CC权利金÷总买入）驱动着色；每格显示年份/贡献率/年末持仓（VGT/SMH/BTC股数）/CC权利金 | 总买入；右侧统计面板含总入金、总资产、CAGR、目标差额；移动端自动切换2列布局
  • 🔥 纪律打卡：连续定投月份计数 + 操作日志热力图
  • 📈 收入渐进加码：四阶段年龄自动计算（起步期/增长期/巅峰期/冲刺期）
  • 🚪 退出策略：47岁按回撤切换防守组合（可自定义保守组合比例）
  • 💰 提款模拟：输入资产/提取率/回报/通胀，计算年/月提取额、耗尽时间、永续率

2. 侧边栏

点左上角 ☰ / 或顶部「My Portfolio」打开。移动端是从左侧滑入的抽屉，点「设置」会推入第二层抽屉。

  • 资产概览：总资产 + 今日收益 + 持仓市值 / 可用现金 + 下次定投日期 + 期权持仓摘要
  • 目标配比：环形图 + VGT/SMH/BTC 目标比例
  • 市场行情：VGT/SMH/BTC 实时行情（标注来源与更新时间）
  • 数据健康：最近云同步 / 最近备份 / 冲突状态，附「重试」「强制上传」按钮
  • ⚙️ 设置（第二层抽屉）：
    • 快捷设置：手动行情 / 云端同步 / 数据与备份 / 投资参数，点哪一项就在下方展开对应面板
    • 高级设置（折叠）：连接配置、JSON 导出导入、券商 CSV 导入、自动备份开关、定投参数（每月金额 / 起点日期 / 起点年龄 / 财务目标）
  • 🎨 配色：5 种主题色（森林/海洋/暖阳/梅紫/极简），切换后记忆偏好
  • 👁 隐私开关：一键隐藏页面上的所有金额
  • 🌙/☀ 暗色/亮色模式：首次自动跟随系统设置，手动切换后记忆偏好
  • 底部：使用文档、清除所有数据

3. 云端同步

入口：侧边栏 → 设置 → 云端同步。日常状态在侧边栏「数据健康」卡片里看。

  • 自动上传：录入交易、入金出金、期权后 2 秒自动推送云端
  • 自动下载：页面打开、切回前台时从云端拉最新数据合并
  • 手动：「上传」用本机覆盖云端；「同步」以云端为准拉回（本机有待同步改动会先确认）
  • 失败处理：上传/下载失败会保留待同步标记，不会丢数据；侧边栏「数据健康」可看失败状态并点「重试」
  • 状态指示：顶部状态栏「云端已同步 / 同步中」，侧边栏数据健康卡片显示最近同步时间与冲突状态
  • 线上版自动填 URL，Token 需在设置 → 云端同步里手动填入（与 Worker 环境变量 AUTH_TOKEN 一致）
⚠ 多设备冲突：两设备同时编辑会触发冲突弹窗，可逐项选择「保留本地」或「使用云端」，也可以一键「全部保留本地」用本机覆盖云端。同步比较采用键序无关算法，不会因数据字段顺序不同产生假冲突。建议一台编辑完等同步完成再换设备。

4. Schwab CSV 导入

  • 拖拽：CSV 文件拖到页面任意位置（显示拖放覆盖层）
  • 按钮：侧边栏 → 设置 → 数据与备份 → 「导入券商 CSV」
  • 支持买入和卖出记录自动识别
  • 导入 VGT / SMH / BTC

5. 数据备份

入口：侧边栏 → 设置 → 数据与备份。

  • 「导出备份」→ 下载 JSON 文件（交易 + 资金 + 参数 + 期权 + 价格），Toast 提示数量
  • 「导入备份」→ 选择 JSON 文件恢复，Toast 提示数量
  • 勾选「自动备份」→ 每次操作自动下载，显示上次备份时间

5.5 清除所有数据

  • 侧边栏最下方的红色「清除所有数据」
  • 二次确认后清空本地 + 云端全部数据（保留同步配置）
  • 清除后刷新页面不会弹出多余的同步提示

6. 现金修正

  • 数据页现金管理区域输入金额
  • 正数增加现金，负数减少现金
  • 自动记录到资金流水（修正+/修正-）
  • 适用于网站记录与实际账户不同步时的手动校准

6.5 股息记录

  • 数据页「现金管理」新增股息录入：选择标的（VGT / SMH，BTC 无股息）、填写金额、点「记录股息」
  • 股息即时计入账户现金余额，并在资金流水生成独立记录（橙色「股息+VGT」标签）
  • 股息仅影响现金余额与资金流水，不计入月度定投（DCA）完成度指标，也不生成 trades

7. Toast 提示

所有操作反馈通过底部居中 Toast 气泡展示，统一毛玻璃效果 + 弹性动画：

  • 成功（绿色）：半透明绿底 + 绿色阴影，用于保存/同步/导出等成功操作
  • 错误（红色）：半透明红底 + 红色阴影，用于失败/解析错误
  • 警告（橙色）：半透明橙底 + 橙色阴影，用于提醒/注意
  • 撤销条：删除/清空类操作后出现的深色提示条，带「撤销」按钮，停留 8 秒（普通提示 2.5 秒、成功提示 3 秒）

所有 Toast 统一毛玻璃效果（backdrop-filter: blur(28px) saturate(180%)），弹性弹入动画（cubic-bezier(.34,1.56,.64,1)）。颜色跟随当前配色方案。

Toast 位置在底部快捷操作按钮上方，避免遮挡。存储空间不足时顶部显示持久橙色警告条。

7.5 待办提醒（铃铛）

移动端顶部状态栏右上角的铃铛展示待办条目，按风险排序，铃铛上带数量角标：

  • Covered Call 覆盖情况：每个标的已卖多少张 Call、覆盖多少股、最近到期日；股价逼近行权价（现价 ≥ 行权价 ×98%）时转为红色高危并显示具体价位
  • 期权到期提醒：剩余 ≤3 天或已过期的合约会提醒，可点「今天不再提醒」当天忽略（次日恢复），避免反复打扰
  • 本月定投差额：本月买入未达定投目标 90% 时提示还差多少

点提醒可直接跳到对应页面（期权 / 操作台）。

7.6 快捷操作

移动端右下角悬浮的「＋」按钮打开快捷操作面板，四个最常用入口：入金、买入、卖出、卖 Call。面板顶部同时显示待办提醒。

8. 表格滚动与表头固定

持仓明细、交易历史、资金流水、期权清单等表格的 表头 已设置 sticky 定位。当表格内容超出卡片高度滚动时，表头自动固定在顶部，始终保持可见，方便对照列名查看数据。

9. 期权模块 · 被动行权 T+1

期权模块采用被动行权 T+1 买回策略（策略建议仅卖 CALL，但类型选择器保留 CALL/PUT 选项）：

  • 实值（ITM）CALL：不再显示红色告警，改为蓝色「临近行权」标签（显示剩余天数），同时显示铁律提示文字
  • 铁律卡片：期权页顶部显示绿色弱底提示「切勿主动平仓，被行权不必慌，T+1 市价买回，踏空代价远高于追高成本」
  • 被动行权：若到期时 CALL 处于实值被行权，在 T+1 手动买回正股，不提前平仓
  • 已结算：被行权后 CALL 状态变为「已结算」褪色显示
  • 权利金流程：录入 CALL/PUT 时权利金实时入账现金，不计入入金/出金，独立追踪

10. 资金流水 · 权利金独立

  • 权利金：录入期权时自动创建资金流水记录，类型为「期权权利金」
  • 独立显示：权利金以蓝色标记，不计入入金（绿色）也不计入出金（红色）
  • 账户现金卡片：顶部「入金」显示排除权利金，仅统计 cashLog 中入金类型
  • 合计归属：资金流水合计中权利金归入流入侧

11. 纪律打卡与投资规划

  • 连续定投：日志页显示连续定投月份计数
  • 操作日志热力图：按日可视化操作频率
  • 收入渐进加码：根据起点年龄自动划分四阶段（起步/增长/巅峰/冲刺）
  • 退出策略：47岁按回撤切换防守组合，可自定义保守组合比例
  • 提款模拟：输入资产/提取率/回报/通胀，计算提取额、耗尽时间和永续率

12. 年度复盘矩阵

日志页纪律打卡卡片下方展示 20 年年度复盘热力矩阵：

  • 热力着色：每格背景色由「年度权利金贡献率」决定（CC权利金÷总买入），颜色越暖权利金贡献越大
  • 每格信息：年份 → 贡献率（加粗大字）→ 年末持仓（VGT/SMH/BTC 股数）→ CC权利金 | 总买入
  • 右侧长线数据：总入金 / 当前总资产 / 长期CAGR / 目标差额
  • 年份起点：从首笔买入或入金记录的实际年份开始，最多 20 年
  • 移动端：自动切换 2 列网格 + 统计面板 2×2 紧凑排列
  • 热力分段：≥12% 深红 / ≥10% 橙红 / ≥8% 浅橙 / ≥6% 米黄 / ≥3% 浅青 / 0.1%+ 浅蓝 / 0% 深蓝

12.5 年度收益归因

数据页「📈 年度归因」卡片，选择年份（默认当前年，可回溯到首笔入金年份）查看当年总收益拆解：

  • 总收益：年初资产 → 年末资产的净增长
  • 拆解条形图：VGT 增值 / SMH 增值 / BTC 增值 / CC 权利金 / 股息 / 其他，每项标注占总收益百分比
  • 明细：年初资产 → 年末资产 · 当年净入金
  • 数据口径：年初持仓取当年 1/1 前累计，年初价取 Yahoo 当年 1/1 收盘价；权利金取自当年卖出 CALL，股息取自当年股息流水
  • 价格不可用：若 Yahoo API 异常无法获取价格，归因结果会显示「⚠️ 价格数据不可用，结果可能不准确」警告，不再返回 0 导致归因失真

13. 移动端

  • 手机浏览器直接打开网址
  • 底部导航 4 个 Tab（均带图标）：仪表盘 / 操作 / 期权 / 记录
  • 顶部状态栏始终保持可见：总资产 + 今日收益 + 实时价 + 同步状态 + 提醒铃铛 + 明暗切换
  • 右下角悬浮「＋」是快捷操作：入金 / 买入 / 卖出 / 卖 Call
  • 侧边栏点左上 ☰（或顶部标题）打开，带遮罩层；点「设置」会推入第二层抽屉
  • 表单和按钮最小 44px 点击区域
  • 顶部状态栏不响应点击刷新（防止误触），手动刷新行情在操作台

14. 暗色模式与配色

首次打开自动跟随系统设置。手动切换后记忆偏好，不再跟随系统。侧边栏点 🌙/☀ 切换暗色/亮色模式。5 种配色方案可选（森林/海洋/暖阳/梅紫/极简），切换后 localStorage 记忆。暗色模式下卡片有明确边界。

15. UI 交互细节

  • 按钮体系统一：所有按钮带阴影、悬浮过渡、按压缩放（:active → scale(.97)）
  • 主要按钮：主色填充 + 主色阴影，悬浮时加深 + 上浮 1px
  • 次要按钮：灰色表面 + 边框，悬浮时上浮
  • 卡片系统统一：统一圆角 + 投影，卡片与底栏分层，悬浮时阴影加深 + 上浮 1px
  • 切换反馈：移动端切换 Tab 时触发 8ms 触觉震动
  • 输入框：聚焦时显示主色光环，并自动滚动进视口（键盘不会挡住正在填的格子）
  • 主色可换：以上主色随侧边栏「配色」选择变化（森林 / 海洋 / 暖阳 / 梅紫 / 极简）
  • 删除确认统一：删除交易、期权、清空记录都走同一个确认卡，确认后仍可撤销
  • 目标配比：VGT 50% / SMH 30% / BTC 20%，在侧边栏「目标配比」与仪表盘读取，目前为固定基准不提供滑块

16. 数据安全

  • 数据不丢失：本机实时保存，改动后 2 秒自动推送云端；推送失败会保留待同步标记，下次操作自动重推
    （已移除「关闭页面时推送」—— 页面关闭时数据未必可用，反而可能用空数据覆盖云端）
  • 同步失败兜底：失败时顶部显示「云同步失败，数据仅存本机」，可直接重试，或先导出备份
  • NaN 防护：期权权利金输入校验 + 现金余额 NaN 自愈，防止数字损坏导致永久死锁
  • 导入安全：CSV 日期格式校验（防 XSS）+ JSON 导入数据归一化（强制类型 + 补 id）
  • 交易安全：卖出超过持仓时拦截（防裸空）+ 行权前重新校验持仓
  • 期权防误删：删除/行权/结算按唯一 id 操作，同步后不会因索引错位误删
  • 存储满警告：localStorage 空间不足时顶部持久橙色警告条，不再静默丢失
  • Worker 安全：API 输入校验（key 白名单 + value 大小限制）+ symbol 正则防注入
