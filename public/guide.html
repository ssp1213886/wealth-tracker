使用文档

Wealth Tracker · 个人投资仪表盘 · 最后更新：2026-11-26

投资策略

本工具围绕长期核心仓、持续定投和年度再平衡设计：

  • 核心仓：QQQM / VGT / SMH 按月定投，当前固定目标为 50% / 30% / 20%
  • 长期持有：不以短期回撤作为减仓依据
  • 年度再平衡：每年只在 12 月 31 日窗口调整一次
核心原则：持续投入、长期持有、年度再平衡，避免高频交易和高复杂度策略。

1. 页面结构

本网站由 4 个页面组成，桌面端用顶部 Tab、移动端用底部导航切换，切换时提供轻微触觉反馈。其中「记录」页内部再分为 明细 与 日志 两个分段，顶部还有一个跨分段生效的搜索框。

📊 仪表盘

  • 总资产指标：账户现金、持仓市值、浮动盈亏、总盈亏
  • 📋 本月定投目标：QQQM/VGT/SMH 动态金额 + 完成/待执行状态
  • 🗺 20年旅程：时间进度条（可配置起始日期和年龄）
  • 💎 路线图：20 年时间旅程 + 财务目标进度，两条轴并排（时间 / 资金）
  • 📈 仓位盈亏：按标的汇总盈亏
  • 🍩 持仓分布：环形图 + 现金池标注

🕹️ 操作台

  • 买卖录入：手动录入交易（日期、标的、数量、价格），支持 QQQM/VGT/SMH
  • 实时价格胶囊：点击后快速带入交易价格
  • 现金管理：入金、出金、现金修正和股息
  • ⚖️ 年度再平衡：仅 12月31日解锁执行，其他日期可预览计算结果（换仓/注资两种模式）

📈 分析

  • 观察列表：持仓与关注标的行情、涨跌和市值排序，支持添加、管理和详情展开
  • 标的切换：QQQM / VGT / SMH 切换查看
  • 趋势图：价格、50 日均线、200 日均线和市场状态历史
  • 时间范围：6 个月 / 1 年 / 2 年
  • 判断规则：仅描述强势、中性和弱势，不包含买卖建议
  • 资产曲线：月末总资产、累计净入金与收益区域
  • 组合风险：高点回撤、集中度、重叠分析和底层资产敞口

📁 记录 · 明细

  • 🔍 搜索：输入标的 / 日期 / 金额即可筛选，命中的卡片会自动展开，右上角显示命中条数，点 × 清除
  • 💰 现金管理：入金/出金/修正/股息 + 余额
  • 📊 持仓明细：标的/持仓/均价/市值/盈亏/收益率，支持列排序（不显示现价，避免与行情卡片重复）
  • 📋 交易历史：方向标签直接写明「买入/卖出多少股」，带标的筛选、列排序，删除按钮在右侧
  • 💵 资金流水：出入金、现金修正和股息分别以独立颜色显示
  • 📈 年度归因：选择年份查看当年总收益拆解（各标的增值 + 股息 + 其他）

📜 记录 · 日志

  • 📋 操作日志：所有录入 / 删除 / 同步动作的流水，可清空
  • 📊 年度复盘矩阵：按年度展示投入完成度、年末持仓、总投入与长期资产统计
  • 🔥 纪律打卡：连续定投月份计数 + 操作日志热力图
  • 📈 收入渐进加码：四阶段年龄自动计算（起步期/增长期/巅峰期/冲刺期）
  • 🚪 退出策略：47岁按回撤切换防守组合（可自定义保守组合比例）
  • 💰 提款模拟：输入资产/提取率/回报/通胀，计算年/月提取额、耗尽时间、永续率

2. 侧边栏

点左上角 ☰ / 或顶部「My Portfolio」打开。移动端是从左侧滑入的抽屉，点「设置」会推入第二层抽屉。

  • 资产概览：总资产 + 今日收益 + 持仓市值 / 可用现金 + 下次定投日期
  • 目标配比：环形图 + QQQM/VGT/SMH 目标比例
  • 市场行情：QQQM/VGT/SMH 实时行情（标注来源与更新时间）
  • 数据健康：最近成功下载 / 上次成功上传 / 最近备份 / 冲突状态，附「重试」「强制上传」按钮（下载 = 云端拉到本机，上传 = 本机推到云端，两条通道独立记录）
  • ⚙️ 设置（第二层抽屉）：
    • 快捷设置：手动行情 / 云端同步 / 数据与备份 / 投资参数，点哪一项就在下方展开对应面板
    • 高级设置（折叠）：连接配置、JSON 导出导入、券商 CSV 导入、自动备份开关、定投参数（每月金额 / 起点年月（两个下拉）/ 起点年龄 / 财务目标）
  • 🎨 配色：5 种主题色（森林/海洋/暖阳/梅紫/极简），切换后记忆偏好
  • 👁 隐私开关：一键隐藏页面上的所有金额
  • 🌙/☀ 暗色/亮色模式：首次自动跟随系统设置，手动切换后记忆偏好
  • 底部：使用文档、清除所有数据

3. 云端同步

入口：侧边栏 → 设置 → 云端同步。日常状态在侧边栏「数据健康」卡片里看。

  • 自动上传：录入交易、入金出金后 2 秒自动推送云端
  • 自动下载：页面打开、切回前台时从云端拉最新数据合并
  • 手动：「上传」用本机覆盖云端；「同步」以云端为准拉回（本机有待同步改动会先确认）
  • 失败处理：上传/下载失败会保留待同步标记，不会丢数据；侧边栏「数据健康」可看失败状态并点「重试」
  • 状态指示：顶部状态栏「云端已同步 / 同步中」，侧边栏数据健康卡片显示最近同步时间与冲突状态
  • 不会打扰你：自动上传成功不弹额外通知（避免连续编辑时连弹）；只有你主动点「上传」才会有一次明确反馈
  • 同步提示胶囊：同步时页面顶部（页头下方）浮出一个居中的小胶囊，不占内容空间、不会把页面顶下去，三种状态尺寸完全一致（132×30），靠颜色 + 图标 + 视觉重量区分阶段 —— 同步中是转圈 +「正在上传…／正在下载…」，成功后变绿色「✓ 已同步 14:32」约 2.2 秒自动收起，失败变红色并写清原因（带红色光晕、视觉上更重，8 秒后收起；重试按钮在顶部失败横幅里，胶囊本身不放按钮，避免尺寸被按钮撑大）
  • 网络不好时不会一直转圈：同步请求超过 15 秒就判定为「连不上云端 · 稍后自动重试」；手机处于离线状态时直接显示「当前离线 · 数据已存本机」，不假装在下载；VPN 重连或切回 WiFi 后会自动补一次同步，不用你手动点
  • 关页面兜底：删除等改动如果来不及等自动同步就退出，会尽力补发一次（只发有改动的部分），下次打开也会自动续传，不需要你手动点上传
  • 线上版自动填 URL，Token 需在设置 → 云端同步里手动填入（与 Worker 环境变量 AUTH_TOKEN 一致）
⚠ 多设备冲突：两设备同时编辑会触发冲突弹窗，可逐项选择「保留本地」或「使用云端」，也可以一键「全部保留本地」用本机覆盖云端。同步比较采用键序无关算法，不会因数据字段顺序不同产生假冲突。建议一台编辑完等同步完成再换设备。

4. Schwab CSV 导入

  • 拖拽：CSV 文件拖到页面任意位置（显示拖放覆盖层）
  • 按钮：侧边栏 → 设置 → 数据与备份 → 「导入券商 CSV」
  • 支持买入和卖出记录自动识别
  • 导入 QQQM / VGT / SMH
  • 没进来说得清：无法识别的行会按原因统计并告诉你，例如「已导入 1 笔交易（跳过 3 行：标的不在核心仓 1、价格无效 1、与已有记录重复 1）」，不会静默少几笔

5. 数据备份

入口：侧边栏 → 设置 → 数据与备份。

  • 「导出备份」→ 下载 JSON 文件（交易 + 资金 + 参数 + 价格），Toast 提示数量
  • 「导入备份」→ 选择 JSON 文件恢复，Toast 提示数量
  • 勾选「自动备份」→ 每次操作自动下载，显示上次备份时间

5.5 清除所有数据

  • 侧边栏最下方的红色「清除所有数据」
  • 二次确认后清空本地 + 云端全部数据（保留同步配置）
  • 清除后刷新页面不会弹出多余的同步提示

6. 现金修正

  • 数据页现金管理区域输入金额
  • 正数增加现金，负数减少现金
  • 填负数会先确认：确认框会写明修完之后剩多少；如果修完可用现金是负数，还会额外警告一次（总资产会跟着变负）。取消则不会改动任何数据
  • 自动记录到资金流水（修正+/修正-）
  • 适用于网站记录与实际账户不同步时的手动校准

6.5 股息记录

  • 数据页「现金管理」新增股息录入：选择标的（QQQM / VGT / SMH）、填写金额、点「记录股息」
  • 股息即时计入账户现金余额，并在资金流水生成独立记录（橙色「股息+VGT」标签）
  • 股息仅影响现金余额与资金流水，不计入月度定投（DCA）完成度指标，也不生成 trades

7. Toast 提示

所有操作反馈通过底部居中 Toast 气泡展示，统一毛玻璃效果 + 弹性动画：

  • 成功（绿色）：半透明绿底 + 绿色阴影，用于保存/同步/导出等成功操作
  • 错误（红色）：半透明红底 + 红色阴影，用于失败/解析错误
  • 警告（橙色）：半透明橙底 + 橙色阴影，用于提醒/注意
  • 撤销条：删除/清空类操作后出现的深色提示条，带「撤销」按钮，停留 8 秒（普通提示 2.5 秒、成功提示 3 秒）

所有 Toast 统一毛玻璃效果（backdrop-filter: blur(28px) saturate(180%)），弹性弹入动画（cubic-bezier(.34,1.56,.64,1)）。颜色跟随当前配色方案。

Toast 位置在底部快捷操作按钮上方，避免遮挡。存储空间不足时顶部显示持久橙色警告条。

8. 表格滚动与表头固定

持仓明细、交易历史、资金流水等表格的 表头 已设置 sticky 定位。当表格内容超出卡片高度滚动时，表头自动固定在顶部，始终保持可见，方便对照列名查看数据。

11. 纪律打卡与投资规划

  • 连续定投：日志页显示连续定投月份计数
  • 操作日志热力图：按日可视化操作频率
  • 收入渐进加码：根据起点年龄自动划分四阶段（起步/增长/巅峰/冲刺）
  • 退出策略：47岁按回撤切换防守组合，可自定义保守组合比例
  • 提款模拟：输入资产/提取率/回报/通胀，计算提取额、耗尽时间和永续率

12. 年度复盘矩阵

日志页纪律打卡卡片下方展示 20 年年度复盘热力矩阵：

  • 热力着色：每格背景色表示当年投入相对最高投入年度的完成度
  • 每格信息：年份 → 投入完成度 → 年末持仓（QQQM/VGT/SMH 股数）→ 总买入
  • 右侧长线数据：总入金 / 当前总资产 / 长期CAGR / 目标差额
  • 年份起点：从首笔买入或入金记录的实际年份开始，最多 20 年
  • 移动端：自动切换 2 列网格 + 统计面板 2×2 紧凑排列
  • 热力分段：≥12% 深红 / ≥10% 橙红 / ≥8% 浅橙 / ≥6% 米黄 / ≥3% 浅青 / 0.1%+ 浅蓝 / 0% 深蓝

12.5 年度收益归因

数据页「📈 年度归因」卡片，选择年份（默认当前年，可回溯到首笔入金年份）查看当年总收益拆解：

  • 总收益：年初资产 → 年末资产的净增长
  • 拆解条形图：QQQM 增值 / VGT 增值 / SMH 增值 / 股息 / 其他，每项标注占总收益百分比
  • 明细：年初资产 → 年末资产 · 当年净入金
  • 数据口径：年初持仓取当年 1/1 前累计，年初价取 Yahoo 当年 1/1 收盘价；股息取自当年股息流水
  • 价格不可用：若 Yahoo API 异常无法获取价格，归因结果会显示「⚠️ 价格数据不可用，结果可能不准确」警告，不再返回 0 导致归因失真

13. 移动端

  • 手机浏览器直接打开网址
  • 底部导航 4 个入口，中间保留快捷操作按钮：仪表盘 / 操作 / ＋ / 分析 / 记录
  • 顶部状态栏始终保持可见：总资产 + 今日收益 + 实时价 + 同步状态 + 提醒铃铛 + 明暗切换
  • 右下角悬浮「＋」是快捷操作：入金 / 买入 / 卖出
  • 侧边栏点左上 ☰（或顶部标题）打开，带遮罩层；点「设置」会推入第二层抽屉
  • 表单和按钮最小 44px 点击区域
  • 顶部状态栏不响应点击刷新（防止误触），手动刷新行情在操作台

14. 暗色模式与配色

首次打开自动跟随系统设置。手动切换后记忆偏好，不再跟随系统。侧边栏点 🌙/☀ 切换暗色/亮色模式。5 种配色方案可选（森林/海洋/暖阳/梅紫/极简），切换后 localStorage 记忆。暗色模式下卡片有明确边界。

15. UI 交互细节

  • 按钮体系统一：所有按钮带阴影、悬浮过渡、按压缩放（:active → scale(.97)）
  • 主要按钮：主色填充 + 主色阴影，悬浮时加深 + 上浮 1px
  • 次要按钮：灰色表面 + 边框，悬浮时上浮
  • 卡片系统统一：统一圆角 + 投影，卡片与底栏分层，悬浮时阴影加深 + 上浮 1px
  • 切换反馈：移动端切换 Tab 时触发 8ms 触觉震动
  • 输入框：聚焦时显示主色光环，并自动滚动进视口（键盘不会挡住正在填的格子）
  • 主色可换：以上主色随侧边栏「配色」选择变化（森林 / 海洋 / 暖阳 / 梅紫 / 极简）
  • 删除确认统一：删除交易和清空记录走同一个确认卡，确认后仍可撤销
  • 目标配比：QQQM 50% / VGT 30% / SMH 20%，在侧边栏「目标配比」与仪表盘读取，目前为固定基准不提供滑块

16. 数据安全

  • 数据不丢失：本机实时保存，改动后 2 秒自动推送云端；推送失败会保留待同步标记，下次操作自动重推
    （已移除「关闭页面时推送」—— 页面关闭时数据未必可用，反而可能用空数据覆盖云端）
  • 同步失败兜底：连续 2 次失败后顶部出现横幅，写明原因并提示「数据仅存本机」，可直接重试，或先导出备份（关掉后 10 分钟内不再打扰）；日常的失败提示在同步胶囊里，8 秒后自动收起
  • NaN 防护：现金余额 NaN 自愈，防止数字损坏导致永久死锁
  • 导入安全：CSV 日期格式校验（防 XSS）+ JSON 导入数据归一化（强制类型 + 补 id）
  • 交易安全：卖出超过持仓时拦截（防裸空）
  • 存储满警告：localStorage 空间不足时顶部持久橙色警告条，不再静默丢失
  • Worker 安全：API 输入校验（key 白名单 + value 大小限制）+ symbol 正则防注入
